**how to run**
1. access to link http://127.0.0.1:8000/
2. add area, bedrooms and location and ENTER
3. read result
**Explain**
1. we set location: Optional[string] = "" so we do not have to fill this value
2. Area and bedrooms are required to fill in defautl so we have to fill values. If not, it will raise 422 error
